# State-Driven Trading Engine Architecture > Strategy-neutral MQL5 architecture demonstrating explicit EA state management and controlled state transitions. ## Project Summary This project demonstrates a state-driven architecture for MetaTrader 5 Expert Advisors. Instead of placing all trading conditions directly inside `OnTick()`, the EA maintains an explicit operational state. This approach can be useful when an Expert Advisor has multiple phases of operation, such as initialization, activation, pausing, and resetting. --- ## Demonstrated States The example implements five states: | State | Purpose | |---|---| | IDLE | Initial or inactive state | | READY | System initialized and waiting for activation | | ACTIVE | Strategy engine is operational | | PAUSED | Strategy temporarily suspended | | RESET | State reset/reinitialization phase | --- ## State Flow ```text ┌──────────────┐ │ IDLE │ └──────┬───────┘ │ ▼ ┌──────────────┐ │ READY │ └──────┬───────┘ │ ▼ ┌──────────────┐ │ ACTIVE │ └──────┬───────┘ │ ▼ ┌──────────────┐ │ PAUSED │ └──────┬───────┘ │ ▼ ┌──────────────┐ │ RESET │ └──────┬───────┘ │ └──────────► READY
