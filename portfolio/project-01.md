# PSARAnchor Signal Engine > Reusable MQL5 signal component demonstrating separation of market-signal logic from trade execution. ## Project Summary The PSARAnchor Signal Engine is a modular MQL5 component designed for integration into larger MetaTrader 5 Expert Advisors. The component provides a clean interface between a strategy's signal layer and its execution layer. It is intentionally designed without order-placement or position-management logic. --- ## What This Demonstrates ### Modular MQL5 Development The signal engine is implemented as a reusable `.mqh` component that can be included by multiple Expert Advisors. ### Signal / Execution Separation The module determines the current signal while leaving execution decisions to the consuming EA. ```text ┌──────────────────────────────┐ │ Trading Strategy │ └──────────────┬───────────────┘ │ ▼ ┌──────────────────────────────┐ │ PSARAnchor Signal Layer │ │ │ │ Active Anchor │ │ Price Relationship │ │ BUY / SELL / NONE │ └──────────────┬───────────────┘ │ ▼ ┌──────────────────────────────┐ │ Execution Layer │ │ │ │ Risk Management │ │ Position Management │ │ Order Execution │ └──────────────────────────────┘
