# PSARAnchor Signal Engine ## Overview A reusable MQL5 signal module designed to separate signal generation from trade execution. The module demonstrates how a trading strategy can maintain an active price anchor and expose a simple BUY/SELL/NONE interface to any consuming Expert Advisor. ## Key Features - MQL5 `.mqh` reusable component - H1 Parabolic SAR configuration - Active anchor price interface - BUY signal when price is above the active anchor - SELL signal when price is below the active anchor - NONE state when no valid anchor or price is available - Dedicated initialization and cleanup functions - No order placement - No position management - No broker-specific execution dependency ## Architecture ```text +---------------------------+ | Consuming Expert Advisor| +-------------+-------------+ | | Signal request v +---------------------------+ | PSARAnchor Signal | | Module (.mqh) | +-------------+-------------+ | v Active Anchor | +-----+-----+ | | Price > Price < Anchor Anchor | | v v BUY SELL
