# BUYSELLCnt Position Monitoring Module > Reusable MQL5 component for monitoring BUY and SELL position state without coupling monitoring logic to trade execution. ## Project Summary The BUYSELLCnt module provides a lightweight interface for inspecting the current position state of a MetaTrader 5 symbol. It demonstrates how position monitoring can be separated from order execution and incorporated into larger Expert Advisor architectures. The component is monitoring-only. It does not: - Open positions - Modify positions - Close positions - Place pending orders --- ## What This Demonstrates ### Position State Monitoring The module can determine: - Number of BUY positions - Number of SELL positions - Total positions - Whether BUY positions exist - Whether SELL positions exist - Whether any position exists ### Reusable MQL5 Architecture The functionality is contained in a standalone `.mqh` module that can be included by other Expert Advisors. --- ## Public Interface ### BUY Count ```cpp BUYSELLCnt_BuyCount()
